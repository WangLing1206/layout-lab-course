# 布局实验室 · Layout Lab

> 一份以案例驱动的**页面布局**教学网站：讲原理、讲取舍、讲为什么这样更好，而不是罗列 CSS 属性。
> 每个知识点都由 **讲解 / 关键代码 / 动态演示** 三块组成，中英双语，全部可交互。
>
> A case-driven, bilingual, interactive course on **page layout** — principles and trade-offs
> rather than a list of CSS properties. Every topic has explanation, key code, and a live demo.

## 二、项目简介

网站围绕「**如何做好页面布局**」组织内容，共 5 章、18 个知识点、18 个可交互演示：

| 章节 | 内容 | 演示 |
| --- | --- | --- |
| ① 设计原则 | 对齐、留白、视觉层次、栅格系统 | 对齐开关 + 参考线、留白刻度、层级比例尺、12 栅格 |
| ② 经典布局模式 | 单栏与行宽、两栏 / 三栏 / 圣杯、F 形与 Z 形 | 行宽测量、五种模式一键切换、眼动路径动画 |
| ③ Flexbox 与 Grid | 主轴与交叉轴、轨道与 fr、命名区域、选型思路 | Flex 试验台、Grid 试验台、`grid-template-areas` 画笔、选型决策器 |
| ④ 响应式布局 | 断点设计、移动优先、`clamp()` 流体排版、容器查询与四类陷阱 | 视口模拟器、流体排版、容器查询与媒体查询对照 |
| ⑤ 案例实战 | 从零设计一个博客首页：需求 → 骨架 → 实现 → 精修 | 线框增删、方案对比、成品预览、改造前后对比 |

**案例主线**：「远山手记」是一份个人技术博客，改造前「能用但不好读」。五章各自解决案例的一个阶段，
前一步的结论是后一步的依据；第 5 章交付完整代码、改造前后对比与一份八条验收清单。

## 三、功能清单

**内容结构**
- 每个知识点固定三块：**讲解**（原理 / 适用场景 / 设计取舍）、**关键代码**（带注释、可复制）、**动态演示**（可动手实验）
- 三块以**三栏切换器**呈现（等宽三栏，切换显示其中一栏），扫读时不必滚过整段代码才能碰到演示；
  切换选择会在同页后续知识点之间记住。无 JS 时切换器自动隐藏，三块按原顺序堆叠，内容不会丢
- 讲解面板是**正文列 + 旁注栏**的编辑型双栏：正文受 68ch 行宽上限约束（不为了填满而拉长），
  「提示」与「设计权衡」移到右侧旁注栏，容器不够宽时自动落回正文之后并以细线分隔
- 每章配章节目录（滚动高亮当前小节）、案例进度指示、上一章 / 下一章导航
- 关键代码块带语法着色与一键复制；代码要点以列表单独解释

**动态演示（全部为真实 DOM 交互，非截图）**
- **参数可调**：滑块实时改变列数、槽宽、版心、间距、比例、字重、`flex` 各项属性、`clamp()` 的三个参数、断点宽度……
- **方案可切换**：单栏 / 两栏 / 三栏 / 圣杯一键切换；Grid 与 Flex 两种实现对比；容器查询与媒体查询并排对照
- **可交互实验**：点击格子涂出 `grid-template-areas` 并实时校验矩形合法性；拖动视口宽度看真实 iframe 按媒体查询重排
- **实时输出**：每个演示下方有一段 CSS，跟着你的操作同步重写 —— 调满意了直接复制
- **前后对比**：同一份代码切换 `state=before` / `after`，直观看到七处修正带来的差别

**双语文案**
- 右上角 `中 / EN` 一键切换，**全站同步**：正文、控件标签、代码注释、演示读数、页面标题、`<html lang>` 与页脚
- 语言选择记入 `localStorage`，也支持 `?lang=en` 直接进入英文
- 缺译文时**优雅退回中文原文**，不会出现空白或 `undefined`

**体验与无障碍**
- 亮 / 暗双主题（跟随系统偏好，可手动切换并记忆）
- 语义化标签、跳转正文链接、键盘焦点环、`aria-live` 播报演示读数
- 尊重 `prefers-reduced-motion`；缩略图与模拟视口用 `aspect-ratio` 避免布局跳动
- 移动优先，320px → 1600px+ 均可读

### 4.3 三个值得说明的实现决定

**① 双语文案：中文写在 HTML 里，英文放配置对象。**
中文直接写在标签内，因此**禁用 JS 时页面依然完整可读**（也利于 SEO）；切换语言时用 `data-i18n`
标记覆盖为英文，切回中文则还原首次加载时抓取的原文。这样只维护「一份 HTML + 一份英文对照」，
不会出现两份 HTML 逐渐漂移的问题。

```
data-i18n="key"             替换 textContent
data-i18n-html="key"        替换 innerHTML（含行内标签时用）
data-i18n-attr="attr:key"   替换属性（可逗号分隔多组）
```

JS 动态生成的文案（演示读数、状态提示）放在同一文件的 `UI` 表里，中英各一份。

**② 交互演示：一个约 200 行的控件工具箱 + 演示注册表。**
滑块 / 分段按钮 / 开关统一派发自定义事件（`lab:change` / `lab:seg` / `lab:toggle` / `lab:ready`），
每个演示只需关心「数据变了以后怎么改样式」，并把等价的 CSS 打印到「实时输出」代码块里 ——
所以演示区展示的不是截图，而是**跟着你操作实时重写的 CSS**。

**③ 语法着色：逐文本节点着色，不破坏双语标记。**
着色器遍历 `pre code` 的文本节点并按语言正则着色，但**跳过带有 `data-i18n` 的子树**，
因此代码注释可以被单独翻译，语言切换时只替换那一个注释节点的文本。

### 4.4 本站如何示范所讲方法

| 技术 | 用在哪里 |
| --- | --- |
| CSS 自定义属性 | `tokens.css` 统一管理颜色 / 间距 / 字号；暗色主题只覆盖令牌，组件样式一行不改 |
| Grid | 整站骨架（目录栏 + 正文栏）、知识点三栏切换器、卡片阵列、演示区、案例骨架与断点重排 |
| Flexbox | 顶栏、控件行、开关组、卡片内部、页脚；靠边用 `auto` margin |
| `clamp()` | 字号刻度 `--step-*` 全部流体，320px → 1600px 无字号断层 |
| 容器查询 | 两处真实用途：4.3 的对照演示（同一卡片在宽 / 窄容器里形态不同），以及讲解面板本身（容器 ≥860px 才把旁注栏并排到正文右侧，否则堆叠在正文之后） |
| 逻辑属性 | `margin-inline` / `padding-inline` / `border-inline`，天然支持 RTL |
| `position: sticky` | 顶栏、章节目录、案例侧栏（均配 `align-self: start`） |
| `aspect-ratio` | 缩略图与模拟视口，避免加载与缩放时的布局跳动 |
| 无障碍 | 语义化标签、skip-link、`:focus-visible`、`aria-live`、`prefers-reduced-motion` |

### 4.5 本地运行与校验

```bash
# 任意静态服务器均可（不要用 file:// 打开，iframe 演示需要 http 环境）
python -m http.server 8000      # 然后访问 http://localhost:8000

# 双语完整性检查：列出漏译与多余词条
node tools/check-i18n.mjs
node tools/check-i18n.mjs --list   # 列出全部词条与中文原文，便于翻译
```

### 4.6 已知边界

- 演示区「实时输出」里的 CSS 注释同样走词条表（`UI` 里的 `c.*`），因此**也会随语言同步切换**；
  注释里嵌着动态数值（间距 px、断点名、列数……），中英语序不同，所以整句作为词条并用 `{n}` 占位符取值，
  而不是在 JS 里拼接字符串。
- 案例成品 iframe 用的是自成一体的小字典（内联在 `frame-blog.html` 里），以便这份成品可以
  被单独打开、单独复制使用，不依赖主站脚本。
- 容器查询、`text-wrap: balance/pretty`、`dvh` 等较新特性在不支持的浏览器里会优雅退化为默认行为。

## 五、开发约定（次要）

- 每个演示的 id 以 `dv-` 开头（如 `#dv-flex`），实时代码块以 `code-` 开头（如 `#code-flex`），
  两者都需要在 `[data-demo]` 容器内或同一区块内。
- 新增文案时先写在 HTML 里（中文），再运行 `node tools/check-i18n.mjs` 拿到缺失的键名，
  补进 `assets/js/i18n.js` 的 `EN` 表即可。
